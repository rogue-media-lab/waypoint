# CVT Fluid Specs by Make

Critical reference — using the wrong CVT fluid can destroy the transmission. Always verify the exact spec before recommending fluid. **Never guess a CVT fluid spec from memory — always search and verify.**

## Mitsubishi

### Outlander Sport / Outlander / Lancer (CVT)
- **Fluid spec:** Mitsubishi Dia Queen ATF **J4** (supersedes J1)
- **Do NOT use:** Nissan NS-3, universal CVT fluids, or any fluid that does not explicitly state J4 compatibility. No universal CVT fluid meets the J4 spec.
- **Drain-and-fill capacity:** ~4.2 quarts
- **Dry fill (full swap / new trans):** 5+ quarts — buy 5 minimum
- **Used trans:** residual fluid coating internals means 4 quarts may be close to correct, but always verify level after starting
- **Level check procedure:** Start, idle to warm, cycle through all gears (P-R-N-D, manual/L modes), check dipstick or fill plug

### PITFALL — J1 vs J4
Mitsubishi superseded J1 with J4. Older manuals and parts sites may still reference J1. J4 is the current correct spec. Do not mix J1 and J4 — if the trans has J1 residue, drain fully before filling with J4.

## Nissan

### Rogue / Altima / Sentra (CVT)
- **Fluid spec:** Nissan NS-3 (or NS-2 on older models — check by year)
- **Do NOT confuse with Mitsubishi J4** — they are NOT interchangeable

## Honda

### Civic / Accord / CR-V (CVT)
- **Fluid spec:** Honda HCF-2 (specific to Honda CVTs)
- **Do NOT use:** Universal CVT fluid or any other make's spec

## General Rule

CVT fluids are NOT cross-compatible between makes. Each manufacturer has a proprietary formulation. Using the wrong fluid causes belt slippage, valve body failure, and catastrophic trans failure. When in doubt, call the dealer parts counter with the VIN.
